## 三、需要后端（马智贤）确认/补齐的接口

前端页面已经全部能点、能渲染，以下 5 个接口没出，对应页面只能先跑演示数据。请按 `{code,msg,data}` + 驼峰返回：

1. `GET /api/v1/goods/my` —— 我的发布列表（`MyPublishes`）
   - 需要字段：`id, title, price, images, goodsStatus, auditStatus, createTime`
2. `GET /api/v1/favorites` —— 我的收藏（`MyFavorites`）
   - 需要字段：`id, goodsId, createTime`，`goods` 子对象含 `title/price/images`
3. `GET /api/v1/orders` + `POST /api/v1/orders/{id}/pay` + `POST /api/v1/orders/{id}/confirm` —— 订单（`MyOrders`）
   - 需要字段：`id, orderNo, goodsId, goodsTitle, price, orderStatus, createTime`
   - `orderStatus` 字典：`WAIT_CONFIRM / WAIT_TRADE / FINISH / CANCEL`
4. `GET /api/v1/chat/messages?toUserId=` + `POST /api/v1/chat/messages` —— 聊天（`Chat`）
   - 需要字段：`id, fromUserId, toUserId, content, createTime`
5. `POST /api/v1/reports` —— 提交举报（`Report`）
   - 入参：`{goodsId, reason, contact}`
