      经 Nginx 访问时：/ws/ 走轮询，不同浏览器可能连到不同实例，各实例独立广播快照、version 并不同步。version 丢弃规则必须保留，否则会看到数据回退。

      WS 推的是裸快照对象，直接取消息体；REST 是统一包络，取 data 字段。两种入口用同一套 version 校验。

      重连后后端不会补发历史快照，页面在 WebSocket onopen 里立刻拉一次 REST 兜底，再接广播。
